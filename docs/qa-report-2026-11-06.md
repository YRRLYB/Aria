## 一、新功能:QQ 推荐体系(对标网易云)

### 探测结论
- `music.musicToplist.Toplist/GetAll` — **可用**(无需 sign):4 大分组 20 个官方榜单,每榜内嵌 3 首样本歌(含 albumMid,但无 songmid)
- `music.musicToplist.Toplist/GetTopList` — 不可用(未签名 500003 / 参数 40000)
- `music.recommend.RecommendFeed` — code 0 但推荐流为空(需要 App 端上下文),弃用
- 榜单内嵌歌只有数字 songId → 通过经典专辑接口 `fcg_v8_album_info_cp.fcg?albummid=` 换回 songmid(实测可用)

### 落地(`server/sources/qq/client.ts` + `contract.ts` + `routes/sources.ts`)
- `getQqDailyRecommendTracks()`:聚合全部榜单内嵌歌曲 → 按"歌名+歌手"去重 → 前 40 首经专辑接口换 mid → **实测 39 首**(父亲写的散文诗/慢倍速/Hong Kong 等),10 分钟缓存
- `getQqRoamTracks(limit, excludeIds)`:榜单池随机 + 排除最近播放,refresh 即重新随机
- 契约新增可选方法 `getDailyRecommendTracks?` / `getRoamTracks?`,通用路由 `GET /api/sources/:id/daily`、`/api/sources/:id/roam`(网易云继续走旧路由,QQ 走新路由)
- 端到端验证:每日推荐 39 首、roam 正常、推荐歌曲可拿到 128K purl(实测"慢倍速")

### 前端(双源切换)
- `useQqData` 扩展 dailyTracks/roamTracks + 懒加载
- **每日推荐 / 私人漫游视图新增 logo 滑块切换**(网易云/QQ),标题、副标题、空态随源变化
- 悬浮球全部适配:7 个节点背后的视图都已双源可用;网易云专属入口(云盘/歌手/探索)悬浮提示标注"网易云"

## 二、关键 bug 修复(本轮)

### 1. QQ 免费歌"时灵时不灵"的真正根因:GetEVkey 付费档毒化 ⭐
- **对照实验**:仅发 `[M500,C400]` → M500 给 purl;混入 `[F000,M800]` → **整个请求被拒(连 M500 都空)**
- 此前"多格式候选一次带全"的设计正是免费歌播放不稳定的元凶
- **修复**:请求严格按档位类别分开——免费歌(pay.play_play=0,搜索时缓存)永远只发免费候选,请求无损也正确降级 128k;VIP 歌走会话级账号能力探测(`vipProbeState`: unknown→探测→capable/incapable),incapable 后不再打接口;换 Cookie 重置状态
- 回归测试覆盖:免费歌降级、能力探测、毒化防护、状态隔离(新增 `resetQqStreamStateForTests()`)

### 2. 网易云搜索"没反应":网络抖动 502
- axios AggregateError(连接层失败)直接 502 → 结果区空白
- **修复**:`retryOnNetworkError` 包住 cloudsearch 三调用(业务错误不重试;网络错误最多 2 次,400/800ms 退避);实测连搜 5 次全 200

### 3. 桌面版(mac)安装包数据目录佐证
- 桌面版 `userData/data/store.json` 的 QQ/网易云 Cookie 均在,双源账号状态正常(排除一个曾怀疑的方向)

## 四、已知限制与建议(非 bug)

1. **QQ VIP 墙**:无绿钻听不了 VIP 歌(加密流红线不解密)。已用 VIP 徽章前置提示;QQ 推荐流(榜单)里 VIP 歌居多,免费歌以翻唱/独立音乐人为主
2. **网易云 VIP**:fee=1 的歌免费账号拿不到高音质(同样有徽章提示);网易云部分歌免费账号可听低音质
3. **mpv 原生引擎**:本机 macOS 14 Intel 无官方构建(0.41/0.42 均要求 macOS 15);无损与 mpv 无关(浏览器引擎已验证 FLAC)。想要 mpv:装 Homebrew 后 `brew install mpv`,App 自动发现
4. **arm64 DMG**:本机 x64,arm64 包内嵌 x64 Electron,M 芯片机器不可用(需在 arm64 机器出包)
5. QQ 歌单写操作、网易云逐字歌词(QRC)等维持原路线图(P1/P2)
6. 本地音乐 UI 行点击的自动化验证未复现(引擎路径已由在线源等价验证);人工点一下即可确认
