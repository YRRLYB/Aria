# 网易云 API 能力与下一步建议

复核日期：2026-10-13。当前版本为 Aria `0.4.2`。本轮优化大队列保存、本地搜索索引，加入按需加载的歌曲百科与制作人员资料，并重新筛选 API 扩展方向。本文依据项目代码、已安装的 `NeteaseCloudMusicApi 4.32.0` 及匿名只读请求核查。

## 已经完成的体验

| 功能 | 当前接入范围 |
| --- | --- |
| 搜索增强 | 单曲、歌手、歌单、用户、专辑、歌词六种模式；输入联想；按当前模式请求与加载更多；歌词结果展示匹配片段 |
| 用户与公开歌单 | 搜索普通用户，查看公开资料、创建或收藏的可见歌单，再进入歌单查看与播放 |
| 完整歌单管理 | 新建公开或私密歌单；自己创建的歌单可增删歌曲、改名、修改介绍、调整歌曲顺序、上传封面；他人的歌单可收藏或取消收藏 |
| 专辑与歌手详情 | 专辑信息与完整曲目；歌手简介、介绍段落、热门曲目和专辑列表 |
| 推荐与播放 | 每日推荐、私人漫游、喜欢歌曲、同步歌词及翻译、实际取流音质与原始/臻品档位 |
| 逐字歌词 | 普通歌词侧栏与沉浸播放逐词高亮；保存毫秒级时间，点击歌词跳转；已有普通歌词缓存可自动更新 |
| 本地曲库批量补全 | 每批最多 20 首，预览资料、封面及歌词候选；显示置信度、改选候选后确认应用；支持撤销最近一次补全 |
| 音乐云盘 | 登录后分页读取自己的云盘，显示数量和容量、歌曲与文件资料；支持搜索、刷新、播放和错误重试 |
| 歌曲百科 | 现在播放页的书本入口；查看实际返回的曲风、BPM、语种、背景和制作人员；按需加载，失败重试与成功内容缓存 |
| 音量标准化 | 音频设置中独立开关，默认关闭；System 使用 AudioWorklet 实时 RMS 调整，WASAPI 使用 mpv 动态响度处理 |

六种搜索共用 `cloudsearch`，对应 `type=1 / 100 / 1000 / 1002 / 10 / 1006`；`1002` 是用户，`100` 是歌手。用户搜索与公开详情不强制登录；用户歌单列表仅显示当前会话有权访问的内容。

歌单写操作要求登录，编辑前重新检查歌单所有权。“我喜欢的音乐”的名称和封面由网易云管理。排序需要完整歌曲集合，歌单已变化或超过当前读取上限时会提示重新打开；上游拒绝会显示错误。歌单标签接口也已接入后端，界面暂未提供标签编辑。

### 本轮功能边界

歌曲百科使用公共歌曲编号，不强制登录。百科和创作者接口各自持久缓存 24 小时，界面仅在点击入口后加载；部分接口失败时保留成功内容并允许重试，完整成功但为空时显示资料缺失。仅展示上游实际返回的资料；没有推测 BPM、生成背景或通过大模型改写内容。本地未关联公开歌曲编号时不显示该入口。

性能基准脚本为 `node scripts/benchmark-library.cjs`。在本机 10000 首合成曲库中，7 次测量的中位数为：队列快照约 322.214 ms → 0.171 ms，连续 50 次本地搜索约 176.872 ms → 22.019 ms。它衡量这两处计算，不包含启动、网络、磁盘或播放耗时，不能直接换算为整体性能提升。

逐字歌词优先读取 `lyric_new` 中的 `yrc`，译文优先使用与逐字时间匹配的 `ytlrc`。歌曲没有逐字数据时显示普通同步歌词；新接口失败或数据缺失时回退 `lyric`。仅展示上游提供的逐字时间，不会给普通歌词猜测词时轴。

批量补全依据歌曲名、歌手、专辑计算匹配分与置信度，自动勾选高置信且候选明确的结果，实际应用仍需要用户确认。默认保留已有封面和歌词，可以单独选择资料、封面、歌词及是否替换。结果存入 Aria 的资料覆盖层，原音频文件不被修改。预览有效期为 15 分钟，后端保留最近 20 个批次的撤销快照；界面提供撤销上次补全，已被后续修改的项目会保留最新结果。此处的匹配是规则评分，没有接入大模型。

云盘当前为读取与播放体验：每次加载 100 首，搜索按歌曲名、歌手或文件名筛选，并继续读取后续分页，界面显示已检索数量。播放先解析云盘歌曲详情再取流，实际可播放性及音质以账号和上游返回为准。**当前没有文件上传、删除云盘文件或云盘匹配纠错功能。**

音量标准化采用实时响度控制，保持用户音量在处理链后端，并限制增益和峰值，减少不同歌曲间音量突变。它没有读取文件中的 ReplayGain 标签，也没有离线分析整曲或专辑响度，不能称为 ReplayGain 或专辑级响度归一化。开启后会处理音频样本；需要原始输出时关闭该开关。

## 下一步优先级

以下为尚未接入的新方向，不再重复推荐此前的智能接续、收藏、歌单体检、云端历史、评论、榜单或 MV。

| 排名 | 建议功能 | 接口 | 核查结果与限制 |
| --- | --- | --- | --- |
| 1 | 听歌识曲 | `audio_match` | 模块与官方示例存在，输入为时长和专用音频指纹；需先实现指纹采集，不能直接提交任意音频字节。本轮未在线验证识别准确率或登录要求；取流仍受账号和版权限制 |
| 2 | 节拍电台 | `radio_sport_get`；复用歌曲百科 BPM | 用户选择节奏或按当前歌曲 BPM 获取一组音乐；匿名 `bpm=90` 请求返回 200 和歌曲，但样例包含 BPM 110，不能承诺严格匹配。歌曲实际播放与音质需账号权益 |
| 3 | 曲风探索地图 | `style_list`、`style_detail`、`style_song` | 匿名请求均返回 200，可浏览曲风树、风格说明与分页歌曲；可以将百科中的曲风接到探索页。无需登录浏览，播放权益独立 |
| 4 | 钢琴 / 吉他谱 | `sheet_list`、`sheet_preview` | 样例歌曲匿名返回乐器、调性、难度和乐谱列表；匿名预览返回 200 空数组，文档说明内容预览需登录。付费或完整内容权限尚未验证 |
| 5 | 播客与有声书 | `dj_catelist`、`dj_recommend`、`dj_program`、`dj_program_detail` | 分类和推荐匿名返回 200；可做节目列表、记住播放位置和倍速。节目详情和取流还需逐项验证，部分节目收费；没有确认章节或文本转录接口 |

如果优先要更智能的交互，可先做听歌识曲的可行性验证；如果优先稳定落地，可先做曲风探索。`aidj_content_rcmd` 虽提供私人 DJ 模块，本轮匿名返回 500；歌词摘录 `song_lyrics_mark` 匿名返回 301。两者暂不建议作为下一版主功能，登录后可用性尚未验证。

本地依赖没有发现能直接提供完整节拍时轴、段落结构或人声 / 伴奏分离的专用模块。百科中的 BPM 是部分歌曲的资料，不能替代音频分析；实现这些能力需独立音频算法或其他服务。

## 桌面本地功能建议

以下能力不依赖新增网易云接口，仍需在 Aria 中实现：

| 功能 | 建议入口与行为 | 实现注意点 |
| --- | --- | --- |
| 睡眠定时器 | 播放选项中选择 15 / 30 / 60 分钟，或本曲结束暂停；结束前可渐弱音量 | 到时控制 Electron 主进程中的播放，避免后台节流；正常暂停和手动改音量不应被覆盖 |
| 缓存管理 | 设置中查看封面、歌词、资料缓存的占用，分别清理并查看最近请求失败原因 | 清理时保留当前播放资源，缓存缺失后自动重新获取 |
| ReplayGain 与整曲响度分析 | 在现有实时标准化基础上，读取文件标签或分析整曲，提供曲目/专辑模式 | 需要新增标签解析、分析缓存和模式切换；当前实时 RMS 功能不能替代此能力 |

云盘、收藏、个人历史及播放记录上报需要登录；部分听歌报告可能需要会员。体检接口的“可用”结果需要结合实际取流判断，不能直接推断完整歌曲或目标音质一定可播放。歌单导入的链接支持范围和匹配率也需要单独实测。

由用户主动发起的资源分享（`share_resource`）也可以评估，但不属于本轮功能范围。

## 验证范围

此前用户搜索、用户公开资料与歌单、专辑搜索与详情、歌手简介与专辑、搜索建议、歌词搜索已使用匿名请求验证真实返回结构，并通过实际 `NeteaseClient` 流程检查。验证使用隔离的 Aria 数据目录，没有修改真实账号中的内容。

本轮新增的在线核查均为**匿名、只读请求**：

- 0.4.2：`song_wiki_summary`、`song_creators` 对歌曲 `1859652717` 返回 200；确认曲风、语种、BPM 68、关联作品及作词 / 作曲 / 编曲 / 制作人的真实结构，并经后端映射测试。
- 0.4.2：`style_list`、`style_detail(tagId=1000)`、`style_song(tagId=1000,size=3)`、`radio_sport_get(bpm=90)`、`sheet_list(id=1859652717)`、`sheet_preview(id=680923)`、`dj_catelist`、`dj_recommend` 返回 200。乐谱预览为空；节拍电台的 BPM 不是严格筛选。
- 0.4.2：`song_lyrics_mark` 返回 301，`aidj_content_rcmd` 返回 500；未据此推断登录后的行为。听歌识曲仅核查模块及指纹示例，没有提交音频或测试准确率。

- `lyric_new`：歌曲 `1859652717`、`191254`、`418603077` 返回逐字数据，`347230`、`186016` 返回普通歌词；共享歌词服务对 `1859652717` 解析出 28 行逐字歌词及 28 行译文。确认真实时间格式、译文对齐与缺少逐字数据的回退范围，不能据此推断每首歌都有逐字歌词。
- `song_wiki_summary`：示例歌曲返回 `code=200`、4 个内容块；内容类型与完整程度随歌曲变化。
- `comment_new`：示例歌曲热门评论请求返回 `code=200`、3 条评论；未验证登录后的发评、点赞或全部排序分页组合。
- `toplist_detail`：返回 `code=200`、64 条榜单摘要；尚未验证每个榜单的完整歌曲集合。
- `simi_song`、`song_music_detail`：示例歌曲返回 `code=200`，核查了响应结构；尚未接入产品，也未验证所有歌曲或账号权益组合。

云盘属于账号私有数据，当前通过模拟接口验证分页、资料映射、详情读取和登录/上游错误处理，没有以匿名请求验证私人云盘内容。专辑与歌手收藏模块已检查本地源码的参数和读写接口，但没有向真实账号执行收藏或取消收藏。

歌单写操作使用模拟接口测试，覆盖所有权检查、特殊歌单限制、完整排序集合、封面转码、缓存失效与上游错误；没有对真实账号执行增删、改名、上传或收藏测试。批量补全覆盖匹配评分、预览、应用、撤销和持久化等本地行为；歌词解析及回退有独立测试，音量算法测试覆盖增益收敛、立体声比例和峰值限制。在线样例成功只证明当时的接口可读及返回结构，不代替完整功能验收。

其余待接能力只确认本地模块和文档存在，尚未逐个在线验证。核查来源为 `server/clients/neteaseClient.ts`、`server/services/neteaseService.ts`、`server/services/lyricService.ts`、`server/lyrics.ts`、`server/routes/localMetadata.ts`，以及本地依赖中的 `module/*.js`、`public/docs/home.md`。封面缓存、标题布局、快捷键、无缝播放、音量标准化和睡眠定时器属于 Aria 本地能力，不增加网易云接口种类。
