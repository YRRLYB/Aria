# Aria 0.3.13 宣传素材

这份文档记录从 0.2.18-beta.0 到 0.3.13-beta.0 的主要变化，也提供一份可以直接发布到小黑盒的文案。配图位于 [`docs/promo-0.3.13/images`](promo-0.3.13/images)。

## 可以直接发布的文案

### 我尝试开发了一个对我胃口的播放器，现在它又完善了一些

我自己算是一个轻度 HiFi 用户，平常会听本地音乐，也会经常听网易云。以前听本地音乐和网易云音乐时，总要在几个播放器之间来回切换，播放队列、歌词、收藏和封面也分散在不同的软件里，使用起来总觉得不太顺手。

所以我决定自己做一个：把本地曲库、网易云喜欢、歌单、歌词、封面和 HiFi 播放放在一个舒服的桌面播放器里。

和 0.2.18 相比，现在的 Aria 增加并完善了本地专辑浏览、网易云同步、歌词绑定、播放历史、频谱、沉浸模式、托盘后台、全局快捷键，以及系统音频、WASAPI 共享和 WASAPI 独占输出。

最近还重点修复了 Windows 音量面板的音乐卡片。无论使用浏览器、共享还是独占模式，都能正常显示歌曲、歌手、专辑和封面，并使用系统界面播放、暂停、上一首和下一首。任务栏悬浮预览也可以直接查看当前歌曲和控制播放。

这次还优化了大尺寸封面、播放状态刷新和闲置 mpv 进程，长时间播放和切换歌曲时会更稳定。项目仍然是 Beta，如果遇到问题，欢迎附上复现步骤、系统和音频设备信息、截图或日志。

项目地址：https://github.com/YRRLYB/Aria

欢迎告诉我你希望 Aria 下一步增加什么功能。喵喵喵。

## 0.2.18 到 0.3.13 的版本脉络

- 0.2.18–0.2.24：持续打磨播放页、频谱、歌词、播放历史和本地曲库入口。
- 0.3.0：重整本地音乐、网易云内容和播放器页面，增加来源切换、艺术家详情和更完整的桌面交互。
- 0.3.4：优化封面解码、玻璃效果、频谱绘制、GPU 和 V8 内存使用，改善大量歌曲场景。
- 0.3.12：完善后台托管、托盘、窗口动画、本地扫描、播放恢复和 WASAPI 共享输出。
- 0.3.13：统一 Windows 原生媒体会话，修复 mpv 共享/独占时的系统音乐卡片，加入任务栏封面预览与控制；同时优化播放状态刷新、封面缩略图、mpv 生命周期和播放切换竞争问题。

完整技术验证见 [`docs/verification-0.3.13-beta.0.md`](verification-0.3.13-beta.0.md)。
