Aria 想解决的事情很简单：本地曲库、网易云喜欢、每日推荐、私人漫游、歌单、歌词和封面，不需要分散在几个入口里。打开一个桌面软件，就能继续听自己的音乐。

项目目前还处在开发测试阶段，功能会继续调整，也可能遇到小 bug。如果你在日常使用里碰到问题，欢迎反馈复现步骤、截图或日志，我会继续修。

## 功能

### 曲库与多音源

- **本地音乐扫描**：读取标题、歌手、专辑、时长、码率、采样率、无损状态和内嵌封面；支持添加多个音乐目录，并在后台自动扫描新增歌曲。
- **Aria 歌单**：保存在本机，可混合本地、网易云、QQ 音乐与 B站歌曲；远程歌曲保存紧凑快照，重启后仍可播放。
- **网易云同步**：支持扫码登录，自动同步头像、昵称、我喜欢的音乐、每日推荐、私人漫游、歌单与音乐云盘（支持浏览、搜索、容量与分页加载）；启动时先用本地快照显示上次内容，再在后台按接口独立刷新，网络请求直连不继承系统代理。
- **QQ 音乐**：搜索、歌词、封面与音质档位齐全；支持手机 QQ 扫码登录（网页端与桌面端都可用）与退出登录。
- **B站音源与视频模式**：支持匿名搜索、视频详情、DASH 音轨与 CC 字幕歌词；扫码或 Cookie 登录后可同步「Aria」收藏夹、使用更高视频清晰度和大会员 FLAC / Dolby 音轨。视频模式采用 16:9 大画面 + 歌词侧栏，支持进度、音量与全屏覆盖控制，切换视频与封面模式时保持当前播放位置。
- **我喜欢与播放源管理**：全部来源聚合展示，也保留本地、网易云、QQ 音乐、B站单来源筛选；设置页可逐源启用或禁用，关闭的源不会出现在搜索里，也不会发起请求。

### 播放与音频输出

- **播放控制**：播放/暂停、上一首/下一首、随机播放、单曲循环、音量、进度条、喜欢按钮和播放队列。
- **HiFi 输出**：支持系统音频、WASAPI 共享输出和 WASAPI 独占输出。
- **十段均衡器**：播放页内直接打开，覆盖 31Hz–16kHz 十个频段、六种预设和手动拖动，支持多选联动、保存与导入/导出自定义预设；系统音频与 WASAPI 输出均实时生效，设置只保存在本机。
- **音质显示与音量标准化**：显示当前歌曲的音质、真实码率、采样率和可用音质档位；设置中可独立开启音量标准化，系统音频与 WASAPI 输出均支持。

### 歌词、封面与资料

- **歌词**：网易云歌曲自动同步逐字歌词与翻译，缺少逐字数据时回退普通歌词；本地歌曲支持联网搜索并绑定歌词。
- **批量补全**：本地歌曲可批量预览歌曲资料、封面和歌词，显示匹配置信度、改选候选并撤销补全。
- **歌曲百科**：播放页点击书本图标，查看曲风、BPM、语种、歌曲背景和作词、作曲等制作人员；按需读取并缓存已有资料。
- **封面、频谱与统计**：读取本地内嵌封面并尝试在线补全，播放页会根据封面颜色调整视觉主题；播放页显示实时频谱，主页和统计页会记录常听歌曲。

### 桌面交互与远程访问

- **桌面体验**：自定义窗口、浅色 / 深色 / 跟随系统三档切换（首页、播放页、队列与设置同步换色）、托盘后台、中文托盘菜单与播放状态缓存。
- **手机远程访问**：设置里开启后，同一局域网内的 [Aria-Mobile](https://github.com/YRRLYB/Aria-Mobile)（Android 版）可以连接桌面端，同步网易云歌单并串流本地曲库（令牌鉴权，仅限可信网络）。
- **应用内更新**：设置 → 版本与更新可检查、下载并重启安装新版本；macOS 未签名包暂不支持自动更新，请手动下载 DMG。

## 下载

当前主要面向 Windows 桌面端，并已适配 macOS Intel 与 Apple Silicon（各一个 DMG）。macOS 构建、签名与双架构说明见 [macOS x64/arm64 文档](docs/macos-x64-arm64.md)。Windows 与 macOS 安装包会放在仓库的 [Releases](https://github.com/YRRLYB/Aria/releases/latest) 或本地 `release/` 目录中。

如果你只是想试用，建议直接安装最新的 beta 包；如果你想参与开发，可以按下面的方式从源码运行。

## 开发

需要 Node.js 20+（推荐 22）与 npm。仓库里不含 `node_modules`、`release/`、`vendor/mpv/`、`dist/` 这类产物，克隆后先安装依赖：

```bash
npm install
npm run dev        # 先打包后端，再同时启动 Vite 与 Electron
```

只跑网页版（浏览器访问 `http://127.0.0.1:5173`，后端由 `npm run dev:server` 提供）：

```bash
npm run dev:server
npm run dev:web
```

常用命令：

```bash
npm test                # 运行 vitest 测试
npm run build:web       # 构建前端产物
npm run build:server    # 构建本地后端
npm run build:desktop   # 含 vendor/mpv 与原生音频模块
npm run dist:beta       # 打包 Windows 安装包 → release/
npm run dist:mac        # 打包 macOS dmg（自动下载/打包 mpv）
```

注意事项：

- `vendor/mpv/` 被 `.gitignore` 忽略，WASAPI / 独占输出需要 `npm run build:desktop`（Windows 与 macOS 都会自动准备 mpv；macOS 会按系统版本和 CPU 架构选择兼容的预编译包）。没有它时播放走系统音频。
- `.musicbox/` 保存运行期数据（账号 Cookie、曲库缓存），同样不入库；新机器上首次运行需要重新扫码登录网易云 / QQ 音乐。
- 账号凭据只存在本机，仓库和安装包里都没有任何账号信息。

## 目录

- `src/`：React 前端界面。
- `server/`：本地后端、音源接口代理、本地音乐扫描、歌词和封面处理。
- `electron/`：桌面窗口、托盘、后台托管、原生音频输出和 IPC。
- `scripts/`：构建和打包辅助脚本。
- `build/`：桌面图标资源。
- `docs/`：设计及构建文档（如 [多源架构方案](docs/multi-source-plan-0.6.0.md)、[macOS 双架构说明](docs/macos-x64-arm64.md)）。
- 移动端：Android 客户端在 [Aria-Mobile](https://github.com/YRRLYB/Aria-Mobile) 独立维护，通过「手机远程访问」与本桌面端配对。

## 说明

网易云、QQ 音乐、B站等相关能力需要登录自己的账号。Aria 不内置任何账号凭据，扫码登录得到的 Cookie、曲库缓存和本地设置都保存在用户本机。

这个项目会继续往日常可用的播放器方向打磨。现在的重点是稳定播放、本地和流媒体统一管理、歌词封面补全、HiFi 输出和更舒服的桌面交互。
