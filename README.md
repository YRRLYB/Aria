# Aria

<img src="./logo.png" width="96" alt="Aria logo" />

Aria 是一个本地音乐与网易云账号统一管理的桌面音乐播放器。项目目标是把本地音乐、网易云喜欢、每日推荐、私人漫游、歌单、歌词和封面补全放进同一个轻量桌面体验里。

当前版本：`0.2.7-beta.0`

## 功能

- 本地音乐库扫描：读取本机音乐目录，展示标题、歌手、专辑、时长、码率、无损状态与封面。
- 网易云 Cookie 登录：同步账号头像、昵称、我喜欢的音乐、每日推荐、私人漫游和收藏歌单。
- 播放页：支持播放/暂停、上一首/下一首、随机播放、单曲循环、音量、进度条、音质切换、喜欢按钮和真实音频频谱。
- 歌词：网易云歌曲自动同步歌词；本地歌曲可以联网搜索并绑定歌词。
- 封面与主题：歌曲封面会影响播放页配色，本地歌曲支持从音频内嵌封面或在线候选补全。
- 播放缓存：记住上次播放的歌曲、进度、音量、音质、随机/循环和侧栏状态。
- 桌面能力：无系统标题栏、自定义窗口按钮、托盘后台托管、中文托盘菜单。

## 开发

```bash
npm install
npm run dev
```

常用命令：

```bash
npm run dev:web
npm run dev:server
npm run build:desktop
npm run dist:beta
```

## 目录

- `src/`：React 前端界面。
- `server/`：本地后端、网易云接口代理、本地音乐扫描、歌词与封面处理。
- `electron/`：桌面窗口、托盘、后台托管和 IPC。
- `scripts/`：打包辅助脚本，例如复制网易云运行时依赖。
- `build/`：桌面图标资源。

## 说明

网易云相关功能需要用户在设置中绑定自己的 Cookie。Aria 不内置账号凭据，所有本地设置和缓存都保存在用户本机。
