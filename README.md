当前源码版本：**0.6.0（开发中）** · [下载已发布的 Windows 安装包](https://github.com/YRRLYB/Aria/releases/latest) · [更新记录](CHANGELOG.md)

Aria 想解决的事情很简单：本地曲库、网易云喜欢、每日推荐、私人漫游、歌单、歌词和封面，不需要分散在几个入口里。打开一个桌面软件，就能继续听自己的音乐。

项目目前还处在开发测试阶段，功能会继续调整，也可能遇到小 bug。如果你在日常使用里碰到问题，欢迎反馈复现步骤、截图或日志，我会继续修。

## 功能

- 本地音乐扫描：读取标题、歌手、专辑、时长、码率、采样率、无损状态和内嵌封面；支持添加多个音乐目录，并在后台自动扫描新增歌曲。
- 本地歌单：独立于网易云创建歌单，从带封面的本地曲库中搜索、多选和添加歌曲，只保存在本机；歌单卡片和详情页均可删除歌单。
- 网易云同步：支持扫码登录，自动同步头像、昵称、我喜欢的音乐、每日推荐、私人漫游和歌单；启动时先用本地快照显示上次内容，再在后台刷新。
- QQ 音乐：0.6.0 新增的第二个在线音源，搜索、歌词、封面与音质档位齐全；支持手机 QQ 扫码登录（网页端与桌面端都可用）与退出登录，右上角账号区按已登录的音源显示头像和昵称。
- 播放控制：播放/暂停、上一首/下一首、随机播放、单曲循环、音量、进度条、喜欢按钮和播放队列。
- HiFi 输出：支持系统音频、WASAPI 共享输出和 WASAPI 独占输出。
- 十段均衡器：播放页内打开，31Hz–16kHz 十个频段、六种预设和手动拖动，支持多选联动、保存与导入自定义预设；系统音频与 WASAPI 输出均实时生效，设置只保存在本机。
- 深色模式：浅色 / 深色 / 跟随系统三档切换，首页、播放页、队列与设置同步换色，选择只保存在本机。
- 音质显示：显示当前歌曲的音质、真实码率、采样率和可用音质档位。
- 歌词：网易云歌曲自动同步逐字歌词与翻译，缺少逐字数据时回退普通歌词；本地歌曲支持联网搜索并绑定歌词。
- 批量补全：本地歌曲可批量预览歌曲资料、封面和歌词，显示匹配置信度、改选候选并撤销补全。
- 音乐云盘：浏览、搜索和播放自己的网易云音乐云盘，显示容量与分页加载进度。
- 歌曲百科：现在播放页点击书本图标，查看曲风、BPM、语种、歌曲背景和作词、作曲等制作人员；按需读取并缓存已有资料。
- 音量标准化：设置中独立开启，系统音频与 WASAPI 输出均支持。
- 封面和主题：读取本地内嵌封面，也会尝试在线补全；播放页会根据封面颜色调整视觉主题。
- 频谱和统计：播放页显示实时频谱，主页和统计页会记录常听歌曲。
- 桌面体验：自定义窗口、托盘后台、中文托盘菜单、播放状态缓存。
- 手机远程访问：设置里开启后，同一局域网内的 Aria Android 版可以连接桌面端，同步网易云歌单并串流本地曲库（令牌鉴权，仅限可信网络）。

0.5.1 新增本地歌单与可视化选歌，歌单支持直接删除；设置中可管理多个本地音乐目录，并通过文件监视自动收录新增歌曲。均衡器移入播放页，支持多频段联动拖动、自定义预设与 JSON 导入导出；新增深色模式，可在设置或标题栏切换。窗口和后端并行启动，首轮网易云数据按接口独立刷新，并用本地快照优先呈现上次的歌单与歌曲；网易云网络请求明确直连，不继承系统代理。右侧队列不再为悬浮操作预留宽度，长歌名最多显示两行。修复移除目录后自动扫描错误残留的问题。0.6.0 的多播放源插件方案见 [多源架构方案](docs/multi-source-plan-0.6.0.md)。

## 下载

当前主要面向 Windows 桌面端，0.6.0 起也开始适配 macOS（`npm run dist:mac` 生成 dmg，需要自备 `vendor/mpv/mpv`，详见 [macOS 适配说明](docs/macos-0.6.0.md)）。测试包会放在仓库的 Release 或本地 `release/` 目录中。

如果你只是想试用，建议直接安装最新的 beta 包；如果你想参与开发，可以按下面的方式从源码运行。

## 开发

需要 Node.js 20+（推荐 22）与 npm。仓库里不含 `node_modules`、`release/`、`vendor/mpv/`、`dist/` 这类产物，克隆后先安装依赖：

```bash
npm install
npm run dev        # 先打包后端，再同时启动 Vite 与 Electron
```

只跑网页版（浏览器访问 http://127.0.0.1:5173，后端由 `npm run dev:server` 提供）：

```bash
npm run dev:server
npm run dev:web
```

常用命令：

```bash
npm test           # vitest
npm run build:web  # 前端产物
npm run build:server
npm run build:desktop   # 含 vendor/mpv 与原生音频模块
npm run dist:beta       # Windows 安装包 → release/
npm run dist:mac        # macOS dmg（需自备 vendor/mpv/mpv）
```

注意事项：

- `vendor/mpv/` 被 `.gitignore` 忽略，WASAPI / 独占输出需要 `npm run build:desktop`（Windows 会自动下载 mpv）。没有它时播放走系统音频。
- `.musicbox/` 保存运行期数据（账号 Cookie、曲库缓存），同样不入库；新机器上首次运行需要重新扫码登录网易云 / QQ 音乐。
- 账号凭据只存在本机，仓库和安装包里都没有任何账号信息。

## 目录

- `src/`：React 前端界面。
- `server/`：本地后端、网易云接口代理、本地音乐扫描、歌词和封面处理。
- `electron/`：桌面窗口、托盘、后台托管、原生音频输出和 IPC。
- Android 版：独立仓库维护（Aria-Mobile），通过「手机远程访问」与本桌面端配对。
- `scripts/`：构建和打包辅助脚本。
- `build/`：桌面图标资源。

## 说明

网易云相关能力需要登录自己的账号。Aria 不内置任何账号凭据，扫码登录得到的 Cookie、曲库缓存和本地设置都保存在用户本机。

这个项目会继续往日常可用的播放器方向打磨。现在的重点是稳定播放、本地和流媒体统一管理、歌词封面补全、HiFi 输出和更舒服的桌面交互。
